# PhysioQC

!!! warning

This package is currently on alpha development stage 


### A toolbox for physiological data QA/QC

`physioqc` is designed to help manual QA/QC of physiological data, at any step of the preprocessing. Inspired by `MRIQC`. For github repository, follow this [link](https://github.com/physiopy/physioqc)

### Overview
Physiological data are messy and prone to artefact (e.g., movement in respiration and pulse, ectopic beats in ECG). One important step in the processing of such data is understanding their quality and how much they got affected by various sources of noise (e.g. movement). PhysioQC is meant to help the user to perform quality check and assessment using a few signal processing metrics and guided visual inspection.
Eventually, we aim at time-based labelling of these data.
