In the meantime, you might find it useful to check out these two Physiopy repos:

1. [physiopy-repository-template](https://github.com/physiopy/physiopy-repository-template) which contains the files for many of these plug-ins, alongside other standard repo set-up files.
2. [physiopy-automations](https://github.com/physiopy/physiopy-automations) which is a repo for testing and documenting GitHub automations used within the Physiopy organisation. It is written to be accessible for beginners.
